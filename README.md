# worldclasshousing.net

Static rebuild of the World Class Housing website (previously on Wix), deployed on Vercel.

- Live: https://worldclasshousing.net (and https://worldclasshousing.vercel.app)
- Vercel project: worldclasshousing (team xforria)
- All pages, blog posts and images are self-contained static files; this repo's content is exactly what is deployed.
- build.py is the generator script used for the rebuild (reference only; the deployed output is committed).
